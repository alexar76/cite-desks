# Contributor Covenant Code of Conduct

## Our pledge

We pledge to make participation in Emberline a harassment-free experience for everyone.

## Standards

- Be precise. This product deals with public-safety adjacent evidence.
- Do not pressure the project to draw fake fire perimeters “so it looks better.”
- No harassment, insults, or personal attacks.

## Enforcement

Report issues to the maintainers via [desk@emberlinedesk.com](mailto:desk@emberlinedesk.com). Maintainers may warn, suspend, or ban.

This code of conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.

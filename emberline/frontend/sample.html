Sample wildfire evidence brief

This example covers the CA Transmission Corridor and uses a prepared fixture. It shows how a brief records thermal detection points, compares them with the previous run and preserves the evidence used to produce the report.

CA Transmission Corridor

Evidence
Detection coordinates, brightness and the recorded weather for the watch area.
Change from the prior run
Points that appeared, disappeared, brightened or dimmed.
Evidence trail
The normalized brief, raw Hub payloads, receipt and SHA-256 file hashes.
